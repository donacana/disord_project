## 설정과 한계

가중치: vector .42 / keyword .14 / title .105 / recency .035 / entity .15 / intent .10 / category .05.
1단계 비율을 70%로 보존하고 직접 관련성·의도·카테고리에 30%를 배정했습니다. 기간 우선순위는 점수 외 별도 선택 단계에 적용합니다.
후보 밖 기사 회수, 별칭 해석, 정확한 인물 인식, 문장 단위 의도 이해는 수행하지 않습니다. 빈 결과는 무관 기사로 채우지 않습니다.
5개 질문의 단일 시점 샘플이며 전체 정확도 개선율로 일반화할 수 없습니다.

장원영 활동 0건은 DB 전체에 활동 기사가 없다는 의미가 아니라, 이번 cosine 후보 20건 안에서 적격 기사를 확보하지 못했다는 의미입니다.
영화 후보에 webtoon/drama로 분류된 개봉 기사가 있어 category만으로 삭제하지 않았습니다. 같은 영화에 관한 서로 다른 제목은 이번 보수적 중복 제거 정책상 유지됩니다.

## 규칙 조정 근거

초기 2단계 비교에서 '극장' 단어가 개봉 의도로 해석되어 산업 정책 기사가 선택됐습니다. 개봉 의도 단어에서 일반적인 '극장'을 제외하고 제목의 법적 사건 충돌을 반영했습니다.
개봉 제목이 분명한 기사도 category가 webtoon인 경우가 있어, 강한 제목 근거가 있으면 category 불일치 감점을 0.08에서 0.02로 완화했습니다.
기본 1단계 가중치의 상대 비율을 보존하되 entity·intent·category 신호를 추가한 설정으로 위 결과를 확인했습니다. 별도 대규모 최적화나 통계적 성능 검증은 수행하지 않았습니다.
